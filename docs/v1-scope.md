# Pixora v1 Launch Scope

Date: 2026-04-09

## In Scope (Ship in v1)

- OTP login and dashboard access
- Create event
- Drive/gallery CRUD
- Photo upload and cover photo
- One QR sharing
- PIN unlock for protected galleries
- Favorites
- Single photo download
- Bulk download (only if stable under staging tests)

## Out of Scope (Hidden for now)

- Reviews
- Analytics
- Domains
- Integrations
- Billing, plans, invoices
- Photo selling
- Unfinished design controls

## Scope Rules

- No new features during the production hardening sprint.
- Every visible action in the UI must have a real backend effect.
- If a module is not backend-backed and tested, it stays hidden.
